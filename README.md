# Odysseus Platform - Android client

This repository contains the full source of the simple Android (Java) library project capable of uploading log entries or events happening on mobile devices - back to the remote [Odysseus Logging Platform](https://odysseus.codetitans.dev).

Once added as a dependency of the Android project OdysseusClient can be hooked into your existing logging infrastructure to also output logs into cloud and let you browse and monitor them there.
